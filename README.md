# Blobby Volley VK Mini App

## Описание
Классическая игра Blobby Volley, адаптированная для VK Mini Apps. Играйте против компьютера, зарабатывайте баллы и тратьте их в меню. Включает дополнительные фичи: ускорение игры, замедление времени и периодическое отключение света.
